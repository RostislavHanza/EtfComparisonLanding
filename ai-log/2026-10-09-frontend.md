
## Rozhodnutí a průběžné kontroly

- Přečteny `AGENTS.md` a `docs/PLAN.md`; zachována předchozí necommitovaná úprava pravidel commitů.
- React + Vite + TypeScript strict + Tailwind přes oficiální Vite plugin. Bez routeru a další UI knihovny; přepínání pomocí query parametru `variant` a historie prohlížeče.
- Pět návrhů: redakční serifový split se seznamem; centrovaný výběr ve dvou krocích; tmavý pracovní panel s dlaždicemi; teplý průvodce s rozbalovacími kartami; kompaktní split s přepínači.
- Výběr 2–3 položek, validace e-mailu a lokální demonstrace výsledného stavu. Žádný požadavek pro odeslání, databáze, analytika ani ukládání kontaktů. Obsah neodemyká skutečné srovnání.
- Pokus načíst primární produktové stránky SPY, DIA a MDY přes `curl --fail` na ssga.com vrátil HTTP 403. Údaje nebyly ověřeny. Použity výslovně označené zástupné položky A–D bez tickerů, číselných finančních údajů a tvrzení o skutečných ETF. Zdrojové odkazy nebyly vydávány za ověřené údaje.
- První `npm view` selhalo při zápisu cache mimo workspace. Oprava: projektový `.npmrc` s `cache=.npm` (již ignorovaná cesta); ověřování TLS ponecháno zapnuté.
- README popisuje návrhy, pořadí sekcí, strategii, spuštění, Vercel a nehotové části.

## Výsledky kontrol

- `npm install --no-audit --no-fund`: úspěšná instalace, vytvořen lockfile. `npm run typecheck` a `npm run build`: prošly; Vite sestavil statický výstup `dist`.
- Chromium přes Playwright (dočasný testovací nástroj v ignorované npm cache, ne závislost aplikace): všech pět variant na šířkách 320, 390, 768 a 1440 px. Ve 20 kombinacích ověřeno: žádný horizontální overflow, jediný hlavní titulek, čtyři možnosti, výchozí dvojice, maximálně tři vybrané položky a pravdivý demo stav po formuláři.
- Ověřeno přepnutí mobilním selectem, obnovení URL, historie zpět, minimum dvou položek, odmítnutí neplatného e-mailu, otevření FAQ; bez JS chyb a bez POST požadavků při těchto kontrolách.
- Produkční preview: všechny varianty přímo přes URL při 390 a 1440 px, načtení sestavených assets, výchozí výběr a klávesový skip link. Pořízeny screenshoty v `/tmp`; nejsou součástí repozitáře. Vizuálně prohlédnuty mobilní screenshoty všech konceptů a desktopový pracovní panel.
- Vizuální kontrola odhalila chybějící glyph diagonální šipky v použitém systémovém fontu; nahrazen standardní šipkou doprava. Nejde o finanční údaj.
- Kompletní WCAG audit, čtečka obrazovky, síťové zpomalení a reálná Core Web Vitals nebyly ověřeny. Žádné produkční nasazení, backendové kontroly ani doručování neproběhly. Konverzní metriky jsou pouze plánované.
- Při dokončení návrhů nebyl vytvořen commit ani proveden push; následná autorizace je zaznamenána níže.
